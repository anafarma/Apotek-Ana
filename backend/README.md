# Ana Farma Backend

Backend Google Apps Script modular.

## Status tahap ini
Foundation only:
- konfigurasi spreadsheet
- registry sheet canonical
- pembacaan spreadsheet
- response API
- health endpoint
- read-only Obat endpoint

Tidak ada mutasi data pada tahap foundation ini.

## Instalasi
Paket backend akan disediakan sebagai ZIP untuk diimpor/sinkronkan. Owner tidak perlu menyalin fungsi satu per satu.
